# 门店操作规范（SOP）

本文件只收系统依赖、但系统不检测或不强制的操作规范。系统行为见 [domain.md](domain.md)。

系统保证记录可追溯：每条记录保存操作人、设备、门店节点收到它的时间（`recorded_at`）和声明的发生时间（`occurred_at`），纠错只追加、不覆盖原记录。
系统不保证记录真实，真实性靠本规范和店长复核。

## 账号

- 只用自己的 PIN 登录，不告诉他人，不替他人登录。
- 离开平板前登出。

## 记录

- **当场记录**：业务发生时由本人在平板上录入，不替他人录入，不在班末集中录入。
- 平板显示「待提交 N 条」时，不刷新页面、不关闭浏览器，等它自动提交。刷新会丢失未提交的记录。
- 事后才录入的，走补录入口，如实填写发生时间，并向当班店长说明原因。
- **录错**：用纠错入口（数量更正或整条冲销）并写明原因。不得另录一条反向记录来抵消。
- **温度记录**：只记录实际测得的温度。到点没测就是漏测，告知店长，不得事后补成按时测量。门店节点宕机期间记在纸上的温度，恢复后走补录入口转录。

## 生产

- 取料前在平板上点「开始生产」。没点时，生产期间发生的盘点不会吸收这次用料，盘点差异会算错。

## 盘点

- 只数货架上的实物，不含在制品。
- 从开始清点到提交，被盘物料不得领用、收货、报损或生产取料。
- 违反时盘点差异会算错，由店长重盘。

## 门店节点宕机

- 改用纸质登记，节点恢复后走补录入口逐条转录。

## 复核

- 店长复核：录入时间明显晚于发生时间的记录、被盘点吸收的记录、纠错、盘点差异、报损。
- 复核的频率与形式见 [domain.md](domain.md) Q11。
